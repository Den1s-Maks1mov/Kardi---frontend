#  Фронтенд частина проєкту (Angular SSR)

Ця папка містить клієнтську частину застосунку, розроблену на фреймворку **Angular** (з підтримкою Server-Side Rendering).

На даний момент, головна мета цієї частини - продемонструвати та протестувати можливість веб=застосунку
записувати відео та зберігати його.

##  Швидкий старт для розробників

Щоб запустити фронтенд локально на своєму комп'ютері, виконайте наступні кроки:

### 1. Перейдіть у папку фронтенду
Відкрийте термінал у корені всього проєкту та перейдіть до папки `frontend`:
```bash
cd frontend
```
### 2. Встановіть залежності
Завантажте всі необхідні npm-пакети (папка `node_modules` згенерується автоматично):
```bash
npm install
```

### 3. Запустіть сервер розробки
Для проєктів із підтримкою SSR вкрай важливо запускати застосунок через локальний Node.js сервер, а не відкривати HTML-файли вручну.
```bash
npm start
```
Після успішної компіляції застосунок буде доступний у вашому браузері за адресою:
 http://localhost:4200/

### Можливі проблеми та їх вирішення
Якщо у вас виникли помилки в терміналі PowerShell, спробуйте у терміналі прописати команду:
```bash
cmd
```
Таким чином, ви відкриєте консоль як адміністратор, і зможете спокійно,
без попереджень про порушення політик безпеки Windows, запустити команду:
```bash
npm start
```
